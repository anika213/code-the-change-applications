# Code the Change application viewer

Open `index.html` in your browser, then click **Import CSV** and select your application responses. No installation or server is required.

Use **Review responses** to flip through applications with Previous/Next or the left/right arrow keys. Search and filter the dashboard to narrow the review list.

CSV files are ignored by Git. The HTML includes only column headings, not applicant responses. Imported data stays in browser memory and must be imported again after a reload.
