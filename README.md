# Code the Change application viewer

Open `index.html` in your browser, then click **Import CSV** and select your application responses. No installation or server is required.

Use **Review responses** to flip through applications with Previous/Next or the left/right arrow keys. Search and filter the dashboard to narrow the review list.

CSV files are ignored by Git. The HTML includes only column headings, not applicant responses. Imported data stays in browser memory and must be imported again after a reload.

## Curating a shortlist

Click **Add to shortlist** while flipping through applications; click again to remove. Stars mark shortlisted applicants in the table. Use **Shortlisted only** to filter the dashboard, or **Export shortlist** to download all shortlisted responses in the loaded CSV, regardless of other filters.

Selections are saved in local browser storage and restored when you reimport the CSV in the same browser and location. Matching uses email, name, school, graduation year, and submission timestamp; changing those fields creates a different selection identity. Clearing browser data removes selections. If storage is unavailable, export before closing. Review navigation keeps the list you opened, so removing a shortlist entry does not skip the next applicant.
